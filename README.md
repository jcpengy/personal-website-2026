# Jess Peng — Personal Website

A minimal portfolio of interactive data visualization projects.

## Local preview

```sh
python3 -m http.server 4173
```

Then open `http://localhost:4173`.

## Deployment

The site is plain HTML, CSS, and JavaScript and can be deployed directly from the repository root on Vercel. Each push to `main` can trigger a production deployment after the GitHub repository is connected to a Vercel project.
